# Silero VAD no ort 2.0.0-rc.14: armadilhas

tipo: armadilha
origem: task #792 · claude · 2026-10-18

- O `ort` só aceita **um `Environment` por processo**: `EnvironmentBuilder::build()` falha com "only one environment is allowed per process" mesmo depois de o primeiro ser solto (o `CURRENT_ENV` guarda um `Weak` para sempre). Guarde o da detecção (`onnx::environment()`) e crie toda sessão nova nele.
- Silero VAD v5 a 16 kHz: entradas `input` [1, 576] (64 amostras de contexto da janela anterior + 512 novas; sem o contexto as probabilidades pioram), `state` [2, 1, 128] f32 e `sr` int64 **escalar** (`Tensor::from_array(((), vec![16000i64]))`); saídas `output` [1, 1] e `stateN`.
- `bundle.resources` em **mapa** no `tauri.conf.json`: o overlay `tauri.onnxruntime-windows.conf.json` (`--config`) é mesclado por JSON merge patch, então mapa + mapa somam as chaves; uma lista no base seria trocada inteira pelo mapa do overlay e o modelo sumiria do .exe.
- O `tauri-build` copia os recursos para `target/<perfil>/` no `cargo build`, e o `generate_context!` falha se o arquivo listado não existe: o modelo precisa estar versionado (não em `target/`).
- O logger do app (`transcriber::install_logging`) só deixa passar `warn`: `log::info!` não aparece. Mensagem que o checklist manual confere vai por `eprintln!("[pointspeak] …")`.
- Fala para testar o VAD sem microfone: qualquer WAV mono 16 bits; o teste `vad_real` (ignorado) aceita `VAD_TEST_WAV` e resampleia com o `MonoResampler` do núcleo.

# Pacotes Linux (.deb/AppImage) com o Tauri

tipo: armadilha
origem: task #806 · claude · 2026-10-18

- `./scripts/build-linux.sh` gera os dois; o AppImage baixa linuxdeploy/AppRun do GitHub (cache em `~/.cache/tauri/`) e roda com `APPIMAGE_EXTRACT_AND_RUN=1` (sem FUSE no runner). Funcionou de primeira neste runner.
- O Tauri não roda `dpkg-shlibdeps`: `Depends` do .deb = webkit/gtk/appindicator padrão + `bundle.linux.deb.depends` (o cpal pede `libasound2t64 | libasound2`). Confira com `readelf -d target/release/pointspeak | grep NEEDED`.
- `dpkg-deb -c` desta máquina lista `usr/...` sem o `./` inicial: compare caminhos normalizados.
- Rodar `tauri build` duas vezes seguidas (deb, depois appimage) relinka o `pointspeak` (o `beforeBuildCommand` regenera o `dist/`): use um só `--bundles deb,appimage`.
- Conferir sem instalar: `dpkg-deb -x <deb> <pasta>` e rodar `<pasta>/usr/bin/pointspeak` (há `DISPLAY=:99` no runner). A `resource_dir()` vira `<pasta>/usr/lib/PointSpeak` (exe/../lib/<productName>), então o ONNX Runtime e o Silero VAD do pacote carregam de verdade.
- Espaço: `target/release/` ~2,2 GB depois do build.
